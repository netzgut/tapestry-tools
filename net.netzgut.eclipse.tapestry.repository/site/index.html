Tapestry Tools for Eclipse

Version @VERSION@

Lightweight Apache Tapestry support for Eclipse: navigation between page and component classes and their resources, refactoring that keeps them together, hover and validation in templates, and content assist in Java and templates.

This is its Eclipse update site. Opened in a browser, it only shows this page.

Requirements

  • Eclipse 2026-09 (4.41) or later, running on Java 25
  • Apache Tapestry 5.9 or later
  • WTP XML editor or the Generic Editor for your templates

Installation

  1. In Eclipse, choose Help > Install New Software…
  2. Add… the update site https://netzgut.github.io/tapestry-tools/
  3. Select Tapestry Tools and finish the wizard.

Releases are PGP-signed. On the first install, Eclipse asks whether to trust the signing key. Its fingerprint is 2965 0907 B006 5376 4FDE  2A24 43F3 9FDF 926D C24B.
